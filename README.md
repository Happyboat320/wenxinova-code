# 文心新述

**文心新述——中华古典文学智能改编与互动平台**以网站为参赛作品的最终呈现形态，访问地址为 [https://wenxinova.cn](https://wenxinova.cn/)。

其目标是让用户真正**读得进经典、问得清疑难、改得出新编、玩得转交互**，在沉浸式互动体验与创作参与中激发创意、共享成果，实现经典传承与文化活化并进。

用户打开站点并注册登录，即可体验文库检索、篇章阅读、文白转换、智能改编、知识图谱、数字共演与社区分享等功能。

因涉及大模型推理与图谱生成，部分功能响应可能需要短暂等待，属正常现象。

## 功能主线

功能按用户路径分为四条主线：

| 主线 | 模块 | 功能 |
| --- | --- | --- |
| **读** | 古典文库 | 文库检索、篇章阅读、文白转换 |
| **创** | 创意工坊 | 风格化改编、剧本杀创作 |
| **演** | 数字共演 | 角色智能体设计、单角色智能体对话、多角色智能体共演编排 |
| **享** | UGC社区 & 个人创作管理 | 社区分享与个人创作管理 |

**知识图谱**贯穿其中，为理解与创作提供结构视角。

## 项目结构

- `Wen_wbsite/frontend/`：React、Vite、TypeScript 前端。
- `Wen_wbsite/backend/`：Express、Prisma 后端及测试、导入脚本。
- `Wen_wbsite/deploy/`：Nginx 与 systemd 部署配置。

本地运行见 [项目说明](Wen_wbsite/README.md)，部署见 [部署说明](Wen_wbsite/DEPLOYMENT.md)，书库导入见 [导入指南](Wen_wbsite/backend/docs/IMPORT_GUIDE.md)。

## 本地文件与版本管理

保留源码、依赖锁文件、数据库迁移、环境变量示例及网站实际使用的静态资源。
真实环境变量、密钥、数据库、导入数据、依赖、构建产物、备份、压缩包及测试生成的报告不进入源码仓库。
原文 TXT、小说目录 Excel、包含书籍数据的本地播种脚本和 API 测试原文样本也不进入源码仓库。书库数据由部署环境另行提供，通过后端导入脚本加载。

历史素材归档在本地 `Wen_wbsite/archive/`，该目录由 Git 忽略。
部署或恢复网站时，需另外提供 `.env`、数据库及书库导入数据；不要将数据库备份放入前端 `public/`。
