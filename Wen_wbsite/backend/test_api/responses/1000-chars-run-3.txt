任氏是个女妖。有位韦使君，名叫崟，排行第九，是信安王李祎的外孙。年轻时放荡不羁，喜欢喝酒。他堂妹的丈夫叫郑六，记不清名字了。郑六早年学习武艺，也好酒贪色。贫穷没有家，寄住在妻子的家族里；与韦崟关系很好，一起游玩居住，形影不离。天宝九年夏季六月，韦崟与郑子一同走在长安街道上，打算去新昌里喝酒。走到宣平坊南面，郑子说有事先告辞，请求离开一会儿，随后再去喝酒的地方。韦崟骑白马往东走。郑子骑驴往南走，进入升平坊北门。偶然遇到三个妇人走在路上，其中有个穿白衣的，容貌非常美丽。郑子见了又惊又喜，赶着驴，忽然跑到她前面，忽然又落在她后面，想调戏又不敢。白衣女子不时回头看他，似乎有意接受。郑子开玩笑说：“长得这么美艳，却步行，为什么呢？”白衣女子笑着说：“有坐骑却不懂得借给别人，不步行又干什么？”郑子说：“我这劣等的驴不足以代替佳人的脚步，现在就把它送给你。我能步行跟着，就满足了。”两人相视大笑。同行的人互相调笑诱惑，渐渐亲昵起来。郑子跟着她们往东走，到了乐游园，天色已经昏黑。看见一所住宅，土墙，有车马出入的大门，房屋很整齐。白衣女子要进去，回头说：“请稍等片刻。”说完就进去了。跟从一个女奴，留在门屏之间，问郑子的姓名和排行。郑子告诉了她，也问她。她回答说：“姓任，排行第二十。”过了一会儿，请他进去。郑子把驴拴在门口，把帽子放在鞍上。先见到一个三十多岁的妇人，出来迎接，是任氏的姐姐。摆上蜡烛，备好食物，举杯喝了几巡酒。任氏换好妆出来，尽情畅饮，非常欢乐。夜深了就寝，她那美丽的姿容，歌舞欢笑的神态，一举一动都艳丽动人，几乎不是人间所有的。天快亮时，任氏说：“该走了。我兄弟们名义上隶属教坊，职属南衙，早晨起来就要出门，不能久留。”于是约定以后再见面就走了。郑子出来后，走到里门，门闩还没打开。门旁有胡人卖饼的铺子，正点着灯，烧着火炉。郑子在帘下休息，坐着等报晓的鼓声，顺便和店主说话。郑子指着昨夜住宿的地方问道：“从这里往东转，有扇门的那家，是谁家的宅子？”主人说：“这是围墙里的荒地，没有宅子。”郑子说：“我刚才经过那里，怎么说没有呢？”和他争辩。主人忽然醒悟，说：“唉！我知道了。这里面有一只狐狸，经常引诱男子去同宿，我已经见过三次了。今天你也遇到了吗？”郑子羞惭，隐瞒说：“没有。”天亮后，再看那个地方，只见土墙和车门还是老样子。往里偷看，都是荒草和废园罢了。回来后，见到韦崟。韦崟责怪他误了约定。郑子不泄露实情，拿别的事来回答。然而思念任氏的妖艳美丽，希望再见她一面，心里常常记着不忘。过了十几天，郑子出游，走进西市的衣店，忽然看见了她，是以前那个女奴跟着。郑子急忙喊她。
