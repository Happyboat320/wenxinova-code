任氏是个女妖。有个韦使君，名崟，排行第九，是信安王李祎的外孙。年轻时放荡不羁，喜欢喝酒。他堂妹的丈夫叫郑六，记不清名字了。郑六早年学习武艺，也好酒好色。他贫穷没有家，寄住在妻子的家族里；和韦崟关系很好，一起游玩居住，形影不离。

天宝九年夏天六月，韦崟和郑子一起在长安街上行走，准备到新昌里去喝酒。走到宣平坊南面时，郑子说有事，请求离开一会儿，稍后自己到喝酒的地方去。韦崟骑着白马往东去了。郑子骑着驴往南，进入升平坊的北门。偶然碰到三个妇人在路上走，其中有个穿白衣的，容貌非常美丽。郑子看见她又惊又喜，赶着驴，一会儿走到她前面，一会儿落到她后面，想挑逗又不敢。白衣女子不时回头看他，神情似乎有所默许。郑子跟她开玩笑说：“这么美丽漂亮，却要步行，为什么呢？”白衣女子笑着说：“有坐骑却不懂得借给别人，不步行又能干什么呢？”郑子说：“我这劣等的驴不足以代替佳人走路，现在就把它送给你。我能够步行跟着，就满足了。”两人相视大笑。同行的人互相挑逗引诱，渐渐亲昵起来。郑子跟着她们往东走，到了乐游园，天色已经昏暗了。看见一座宅院，有土墙和车门，房屋很严整。白衣女子要进去时，回头对郑子说：“请稍等一会儿。”就进去了。跟随着她的一个女奴，留在门屏之间，问郑子的姓名和排行。郑子告诉了她，也问她。她回答说：“姓任，排行第二十。”过了一会儿，里面请他进去。郑子把驴拴在门口，把帽子放在鞍上。进去先见一个三十多岁的妇人，来迎接他，这就是任氏的姐姐。点上蜡烛摆上食物，举杯喝了好几轮酒。任氏重新化好妆出来，畅饮极欢。夜深了就寝，她美丽的姿容、动听的歌声笑语、一举一动都艳美动人，几乎不是人间能有的。

将要天亮时，任氏说：“该走了。我家的兄弟隶属教坊，职属南衙，早晨要起来出去，不能久留。”于是约好以后见面的时间就离去了。郑子离开后，走到里门，门还锁着没开。门旁有胡人卖饼的铺子，正点着灯烧着炉子。郑子在帘下休息，坐着等候开门的鼓声，就和店主聊天。郑子指着昨晚住宿的地方问道：“从这里往东转，有一座门的，是谁家的宅子？”主人说：“这里只是墙边的空地，没有宅子。”郑子说：“我刚才经过那里，怎么说是没有呢？”跟他争辩。主人忽然醒悟，说：“哦！我知道了。这里面有一只狐狸，经常引诱男子去和她过夜，我已经见过三次了。今天你也遇到了吗？”郑子羞惭，隐瞒说：“没有。”天亮以后，再去看那个地方，只见土墙和车门跟原来一样。往里面偷看，全是荒草和废园罢了。

回去以后，见到韦崟。韦崟责备他失约。郑子不透露实情，用其他事来搪塞。然而想念那女子的美艳，希望再见她一面，心里常常存着这个念头不忘。过了十多天，郑子外出游玩，走进西市的衣肆，忽然看见了她，之前那个女奴跟着。郑子急忙喊她。任氏侧着身子在人群中躲避。郑子连喊几声追上前去，她才背对着站着，用扇子遮住身后，说：“你已经知道我的底细了，为什么还要靠近我？”郑子说：“就算知道了，又有什么妨碍？”她回答说：“这事很羞耻，难以见人啊。”郑子说：“我这么苦苦想你，你忍心抛弃我吗？”她回答说：“我怎么敢抛弃你，只是怕你厌恶我罢了。”郑子发誓，言辞更加恳切。任氏这才回眸放下扇子，光彩艳丽和先前一样。她对郑子说：“人世间像我这样的不是没有，只是你自己不认识罢了，不要只怪我一个。”郑子请她再和自己欢好。她回答说：“像我们这一类的，被人厌恶忌讳，不是别的原因，是因为会伤人。我却不是这样。如果你不厌恶我，我愿意终身侍奉你。”郑子和她商量找住的地方。任氏说：“从这里往东，有棵大树从屋梁间露出来的地方，门巷幽静，可以租来住。前些日子从宣平坊南边骑着白马往东走的，不是你妻子的兄弟吗？他家里有很多器具，可以借来用。”——那时韦崟的伯父叔父都在四方任职，三院的器具都贮藏在家里。——郑子照她说的去找到那房子，又去找韦崟借器具。韦崟问他用来做什么。郑子说：“新得到一个美人，已经租好房子，借些器具来备用。”韦崟笑着说：“看你的样子，一定是遇上了丑陋怪异的女子，哪里能有多漂亮！”韦崟便把帐幔床席之类的用具都借给他，还让一个聪明机灵的家僮跟着去看。过了一会儿，家僮跑回来报告，气喘吁吁，汗流浃背。韦崟迎上去问：“有吗？”又问：“容貌怎么样？”家僮说：“奇了！天下从来没有见过的美人啊！”韦崟亲戚族广，而且一向纵情游乐，认识很多美女。就问：“比某某谁美？”家僮说：“完全不能比！”韦崟把认识的漂亮女子一个一个比较，说了四五个，家僮都说：“不能比。”当时吴王的女儿排行第六的，是韦崟的表妹，丰艳如神仙，在表亲中向来推为第一。韦崟问：“和吴王家的第六个女儿比怎么样？”家僮又说：“不能比。”韦崟拍手大惊说：“天下难道有这样的美人吗？”连忙让人打水洗脖子，戴好头巾，涂好嘴唇就去了。

到了那里，郑子恰好出去了。韦崟进门，见小童拿着扫帚正扫地，有一个女奴在门口，其他什么也没看见。向小童询问，小童笑着说：“没有。”韦崟环视室内，看见红裙子从门下露出。凑近察看，见任氏藏身在门扇后面。韦崟把她拉出来，到明亮处一看，简直比传说的还要美。韦崟爱得发狂，就搂住她强行非礼，她不肯顺从。韦崟用力强逼，正在危急时，她说：“服了。请稍微松开一下。”等他松了手，她又像刚才一样抵抗。这样反复了好几次。韦崟用力紧紧抱住她。任氏力气用尽，汗流如雨。料想无法脱身，便放松身体不再抗拒，但神色惨变。韦崟问：“为什么不高兴？”任氏长叹一声说：“郑六真是可怜啊！”韦崟问：“什么意思？”她回答说：“郑生有六尺之躯，却不能保护一个女人，岂是大丈夫！而且您年轻时豪奢放纵，见过很多美女，像我这类的见得多了。而郑生只是个穷苦卑贱的人，能让他称心满意的，只有我一个而已。您忍心用自己的富余，来夺取别人所缺少的吗？可怜他穷困饥饿，不能自立，穿您的衣服，吃您的食物，所以才被您所控制。如果能有粗粮充饥，就不至于落到这地步了。”韦崟豪爽仗义，听了她的话，立刻放开她。整衣道歉说：“不敢。”一会儿郑子回来了，和韦崟相视而笑。

从此以后，凡是任氏的柴米肉食，都由韦崟供给。任氏时常来往，出入有时坐车骑马，有时步行，不住在固定的地方。韦崟每天和她游玩，非常欢快。每每互相亲昵，无话不说，但始终没有发生关系。所以韦崟爱护她敬重她，一点儿也不吝惜，每次吃喝，从没忘记过她。

任氏知道韦崟爱自己，便借机道谢说：“承蒙您这样厚爱，实在愧疚。只是我以卑陋的姿质，不足以报答您的心意；而且我不能辜负郑生，所以不能顺从您的欢心。我是秦地人，从小长在秦城。家里本是乐人，中表亲属很多都做了别人的宠妾，因此长安的烟花巷陌，我都熟悉。如果有漂亮女子，您喜欢却得不到的，我可以替您弄来。愿意用这个来报答您的大德。”韦崟说：“太好了！”街市上有个卖衣的妇人叫张十五娘的，肌肤白嫩光洁，韦崟一向喜欢她。就问任氏认不认识她。任氏说：“她是我的表姐妹，弄来很容易。”十多天以后，果然把她带来了。几个月后韦崟腻烦了，便算了。

任氏说：“市井中人容易得到，不足以施展我的本事。如果有幽居绝色难以谋得的，您说说看，我愿意尽力想法子。”韦崟说：“前天寒食节，我和几个朋友在千福寺游玩。看见刁缅将军在殿堂上奏乐。有个善于吹笙的，年纪十六岁，双鬟垂到耳边，娇美的姿态艳丽绝世。你认识她吗？”任氏说：“这是宠奴。她的母亲就是我的表姐。想要她可以办到。”韦崟在席下下拜，任氏答应了。于是她出入刁家。过了一个多月，韦崟催问她想到办法了没有。任氏说愿意拿两匹双丝细绢作贿赂。韦崟照办了。两天后，任氏和韦崟正在吃饭，刁缅派家奴牵着青黑色的马来迎接任氏。任氏听到召唤，笑着对韦崟说：“成了。”

原来，开始时，任氏让宠奴生了一种病，针灸吃药都不减轻。她母亲和刁缅正非常忧虑，打算去请巫医。任氏暗中贿赂巫师，指着自己住的地方，让巫师说去那里住就能痊愈，是吉利的。等到来看病时，巫师说：“在她自己家不利，应该搬到东南方向某个地方住，以摄取生气。”刁缅和她母亲仔细察看那个地方，正是任氏的宅子所在地。刁缅便请求让她去住。任氏假装以房子狭小推辞，经再三恳求才答应。于是用车载着衣服玩物，连同她母亲一起送到任氏那里。到了以后，病就好了。没过几天，任氏暗中引韦崟去和她私通，过了一个月就怀孕了。她母亲害怕，赶快把她带回去交给刁缅，从此就断绝了。

后来有一天，任氏对郑子说：“你能弄到五六千钱吗？我要替你谋利。”郑子说：“可以。”于是向人借了钱，得到六千钱。任氏说：“有人到市场上卖马，马的大腿上有一块疵斑，可以
