任氏是个女妖。有位韦使君，名叫韦崟，排行第九，是信安王李祎的外孙。年轻时放荡不羁，喜欢喝酒。他堂妹的夫婿叫郑六，记不清他的名字了。郑六早年习练武艺，也喜好酒色。因为贫穷没有家业，寄居在妻子的家族里；和韦崟关系很好，一同游玩居住，形影不离。

天宝九年夏季六月，韦崟和郑子一同在长安街道上行走，准备去新昌里喝酒。走到宣平坊南边时，郑子说有事先告辞，说随后再去喝酒的地方。韦崟骑着白马往东去了。郑子骑着驴往南走，进入升平坊的北门。偶然遇到三个妇人在路上行走，其中有个穿白衣的，容貌非常美丽。郑子看见她又惊又喜，催动他的驴，忽而跑到她们前面，忽而落在她们后面，想要挑逗却又不敢。白衣女子不时回头看他，似乎也有接受的意思。郑子戏弄她说：“长得这么美艳，却徒步走路，为什么呢？”白衣女子笑着说：“有坐骑却不晓得借给人用，不走路还能怎样？”郑子说：“我这劣等的驴子不足以代替佳人步行，现在就把驴子送给你骑。我能够步行跟着，就满足了。”两人相视大笑。同行的其他人也互相调笑引诱，渐渐亲近起来。

郑子跟着她们往东走，到了乐游园，天色已经昏黑了。看见一座宅院，有土墙和可以通车的大门，房屋非常整齐。白衣女子将要进去，回头说：“请稍等片刻。”便进去了。跟随她的一个女奴，留在门屏之间，问郑子的姓名和排行。郑子告诉了她，也反问对方。女奴回答说：“姓任，排行第二十。”过了一会儿，女奴请他进去。郑子把驴拴在门口，把帽子放在马鞍上。这时才看见一个三十多岁的妇人，出来迎接他，这就是任氏的姐姐。堂上点起蜡烛，摆上食物，举杯喝了几轮酒。任氏重新梳妆后出来，两人畅饮，极为欢乐。夜深了才就寝，她那娇美的姿容、优美的体态，唱歌说笑的神情，一举一动都明艳动人，几乎不是人间所能有的。

天快亮时，任氏说：“该走了。我的兄弟们名义上隶属教坊，职务归属南衙，早晨起来就要出去，不能久留。”于是约定后会之期才离去。郑子走出来，到了里门，门闩还没有打开。门旁有一家胡人卖饼的铺子，正点着灯、烧旺炉火。郑子在他们的门帘下歇息，坐着等待报晓的鼓声，于是和店主攀谈。郑子指着昨夜住宿的地方问道：“从这里往东转，有一扇门的那座宅院，是谁家的？”主人说：“那里是坍塌的荒地，没有什么宅院。”郑子说：“我刚才还路过那里，怎么能说没有呢？”和他争辩不休。主人忽然醒悟，就说：“哎呀！我知道了。这里有一只狐狸，多次引诱男子去同宿，我曾经见过三次了。如今你也遇上了吗？”郑子羞惭地隐瞒说：“没有。”天亮后，再去看那个地方，只见土墙和通车的大门还和原来一样。窥看里面，都是荒草和废园罢了。

回去后，见到韦崟。韦崟责备他失约。郑子没有泄露实情，用别的事情来搪塞。但回想着任氏的美艳，希望再见她一面，心里一直记挂着不能忘怀。过了十几天，郑子出游，进入西市的衣料铺子，忽然瞥见了她，先前那个女奴跟随着。郑子急忙喊她。
