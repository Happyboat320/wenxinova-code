任氏是个女妖。有个姓韦的使君，名叫崟，排行第九，是信安王李祎的外孙。他年轻时放荡不羁，喜欢喝酒。他的堂妹夫叫郑六，名字已经不记得了。郑六早年练习武艺，也好酒好色。因为贫穷没有家，就寄居在妻子娘家；和韦崟很合得来，两人常常在一起游玩居住，从不间断。

天宝九年夏季六月，韦崟与郑子一同走在长安街上，打算到新昌里去喝酒。走到宣平坊南面时，郑子说有事先告辞，要离开一下，随后再去喝酒的地方。韦崟骑着白马往东去了，郑子骑着驴往南，进了升平坊的北门。恰好遇见三个女子走在路上，其中有一个穿白衣的，容貌极为美丽。郑子见了她又惊又喜，催着驴子，忽而跑到她们前面，忽而落在她们后面，想挑逗却又不敢。白衣女子也不时用眼角看他，神情似乎有所默许。郑子便跟她开玩笑说：“像你这样美艳动人，却要步行，为什么呢？”白衣女子笑着说：“有坐骑却不懂得借给别人，不步行又能怎样？”郑子说：“我这头驴虽然不好，不足以代替佳人走路，现在还是送给你吧。我能步行跟在后边，就满足了。”两人相视大笑。同行的人也跟着互相调笑挑逗，渐渐亲近起来。

郑子跟着她们往东走，到乐游园时，天已经昏黑了。看见一座宅院，有土墙和车门，房屋十分齐整。白衣女子要进去时，回头说：“请你稍等一下。”便进去了。跟着她的一个女奴留在门屏之间，问郑子的姓名和排行。郑子告诉了她，也问她。女奴回答说：“姓任，排行第二十。”过了一会儿，他被请了进去。郑子把驴拴在门口，把帽子放在鞍上。进去先看见一个三十多岁的妇人，前来迎接他，原来是任氏的姐姐。屋里点起蜡烛，摆上酒食，喝了好几杯酒。任氏换了妆出来，大家畅饮，极为欢快。夜深之后就寝，任氏那美好的姿容、唱歌笑语的神态、举手动脚的姿态，样样都妩媚动人，几乎不是人间能够有的。

天快亮的时候，任氏说：“你该走了。我的兄弟名籍挂在教坊，职属南衙，早晨就要出去，不能久留。”于是约好以后再见面，就让他走了。郑子走过后，到了里门，门闩还没有打开。门旁有胡人卖饼的铺子，正点着灯、烧着炉子。郑子在饼铺的帘子下歇息，坐在那里等候报晨的鼓声，便和店主人闲谈。郑子指着昨晚住过的地方问：“从这里往东转，有一座门的那是谁家的宅院？”店主人说：“那里是断墙荒地，根本没有宅院。”郑子说：“我刚才还从那里经过，怎么说是没有呢？”和他争辩起来。店主人突然醒悟，就说：“唉！我知道了。这里有一只狐狸，常引诱男子去过夜，我已经见过三次了。今天你也遇上了吗？”郑子不好意思，隐瞒说：“没有。”

天亮之后，再去看那地方，土墙和车门仍和原来一样。往里面偷看，只见杂草丛生和废园罢了。回去后，见到韦崟，韦崟责怪他误了约定的时间，郑子没有说出实情，用别的事情搪塞过去。但心里仍想着任氏的美貌，希望再见到她一面，这心思一直存着没有忘。

过了十多天，郑子出门游玩，走进西市的衣铺，忽然看见了她，那个以前的女奴跟着她。郑子急忙喊她。
