任氏是个女妖。有个韦使君，名叫韦崟，排行第九，是信安王李祎的外孙。年轻时放荡不羁，喜欢喝酒。他堂妹的丈夫叫郑六，记不清他的名字了。郑六早年学习武艺，也好酒好色。家里贫穷没有住处，寄居在妻子的家族中；和韦崟关系很好，一起游玩居住从不分开。天宝九年夏季六月，韦崟和郑子一同在长安街道上行走，准备去新昌里喝酒。走到宣平坊南面时，郑子说有事先告辞，请求离开一会儿，稍后到喝酒的地方会合。韦崟骑着白马向东去了。郑子骑着驴往南，进入升平坊的北门。偶然遇到三个妇人在路上行走，其中有个穿白衣的，容貌非常美丽。郑子见到她又惊又喜，赶着驴，忽然跑到她前面，忽然落到她后面，想挑逗又不敢。白衣女子不时地回头看他，似乎有意接受。郑子开玩笑说：“像这样美艳，却要步行，为什么呢？”白衣女子笑着说：“有坐骑却不懂得借给别人，不步行又能怎样？”郑子说：“我这破驴不足以代替佳人的脚步，现在就把它献给您。我能步行跟从，就心满意足了。”两人相视大笑。同行的妇人互相打趣挑逗，渐渐亲昵起来。郑子跟着她们向东，到了乐游园，天已经昏黑了。看见一座宅院，有土墙和车门，房屋很整齐。白衣女子要进去，回头说：“请稍等一下。”便进去了。身后跟着一个女仆，留在门屏之间。郑子问她姓名排行，郑子告诉了她，也问她。回答说：“姓任，排行第二十。”不一会儿，有人请他进去。郑子把驴拴在门口，把帽子放在鞍上。先看到一个三十多岁的妇人，出来迎接他，那是任氏的姐姐。点起蜡烛摆上食物，举杯喝了几轮酒。任氏换了妆出来，畅饮极欢。夜深了就寝，她的美丽姿容，唱歌谈笑的神态，举动都艳丽动人，几乎不是人间能有的。快天亮时，任氏说：“可以走了。我家的兄弟名籍隶属于教坊，职属南衙，早晨就要出来，不能久留。”于是约定后会的日期就走了。他们走后，走到里门口，门闩还没打开。门旁有胡人卖饼的店铺，正点灯烧炉。郑子在他们的帘子下休息，坐着等开门的鼓声，于是和店主攀谈。郑子指着昨晚住的地方问道：“从这里往东转，有一扇门的那座宅院，是谁家的？”店主说：“这里原是墙倒后的空地，没有宅院啊。”郑子说：“我刚才还经过那里，怎么说没有呢？”和他争辩。店主忽然醒悟，说：“哦！我知道了。这里有一头狐狸，常引诱男子去过夜，我曾经见过三次了。今天你也遇到了吗？”郑子羞愧地隐瞒说：“没有。”天亮后，再去看那地方，只见土墙和车门还和原来一样。往里看，都是杂草丛生的荒地和废园子罢了。回到住处见到韦崟，韦崟责备他失约，郑子没有透露实情，用别的事来搪塞。然而想念她美丽的容貌，希望再见她一面，心里常存不忘。过了十几天，郑子出游，走进西市的衣铺，猛然看见她，从前那个女仆跟着她。郑子急忙喊她。任氏侧过身在人群中躲闪回避。郑子连连呼喊并向前靠近，她才背对站着，用扇子挡在身后，说：“你已经知道真相了，为什么还要靠近我呢？”郑子说：“就算知道，又有什么关系？”她回答说：“这种事太羞耻了，难见人。”郑子说：“我这样苦苦想你，你忍心抛弃我吗？”她回答说：“怎么敢抛弃你，只是怕你厌恶我罢了。”郑子发誓，言辞越来越恳切。任氏才回过头，放下扇子，光彩艳丽和从前一样。她对郑子说：“人间像我这样的不是没有，只是你不认识罢了，不要只拿我当怪事。”郑子请她再续欢情。她说：“凡是像我这一类的，被人厌恶忌恨，没有别的原因，是因为会伤人。我却不是那样。如果你不厌恶我，我愿意终身侍奉你。”郑子和她商量找住的地方。任氏说：“从这里往东，有一棵大树高出屋檐的那家，门巷幽静，可以租来住。前些时从宣平坊南面骑着白马往东的那个人，不是你妻子的兄弟吗？他家里有很多家具器物，可以借来用。”——这时韦崟的伯叔们都到外地任职去了，三院的家具器物都储藏在家里。——郑子照她的话去找那房子，又到韦崟那里借家具。韦崟问他用来做什么。郑子说：“新得了一个美人，已租好了房子，借些器具来备用。”韦崟笑着说：“看你的模样，一定是遇到了个丑八怪，哪会有什么绝色美女！”韦崟还是把帷帐床席之类全借给了他，派了个聪明机灵的男仆跟着去偷看。不一会儿那仆人奔跑回来禀报，气喘吁吁，汗流浃背。韦崟迎上去问：“有吗？”又问：“容貌怎么样？”那人说：“太奇怪了！普天下从没见过这样的！”韦崟的亲族广泛，而且向来纵情游乐，见惯了美丽女子。于是问：“比某某谁美？”仆人说：“不是同一等次的！”韦崟把自己认为最美的四五个人都拿来比，仆人都说：“不是同一等次。”当时吴王有个第六个女儿，是韦崟的内妹，浓艳如神仙，在表亲中一向被推为第一。韦崟问：“比吴王家第六个女儿谁美？”又说：“不是同一等次。”韦崟拍手大惊说：“天下难道有这样的人吗？”立刻叫人打水洗脖子，整理头巾，涂了嘴唇就前去。到了那里，郑子恰好出去了。韦崟进门，只见一个小男仆拿着扫帚正在扫地，有一个女仆在门口，别的没看见。就问小童，小童笑着说：“没有这个人。”韦崟环视室内，看见红裙摆从门下露出。靠近细看，见任氏缩身躲在门扇之间。韦崟拉她出来，到亮处一看，美得超过传闻的。韦崟爱她爱得发狂，就抱住她强行非礼，她不顺从。韦崟用力制伏她，正当急切时，她忽然说：“顺从了。请稍微松开一下。”等韦崟放松了，她又像先前一样拼命抗拒。这样反复好几次。韦崟于是使出全力紧紧抱住她。任氏力气用尽，汗如雨下。估计自己躲不过了，便放松身体不再抵抗，但神情变得惨然。韦崟问：“怎么脸色这样不高兴？”任氏长叹一声说：“郑六太可怜了！”韦崟说：“什么意思？”她回答说：“郑生有六尺高的身躯，却不能保护一个女人，算什么大丈夫！况且您年轻豪奢，得到的美女很多，像我这样的遇到得多了。而郑生是个贫穷低贱的人，能让他称心如意的，只有我一个而已。您忍心用自己富余的心，去夺取别人不足的东西吗？可怜他穷困饥饿，不能自立，穿您的衣服，吃您的饭，所以才被您制约罢了。如果能让他吃上粗粮，他就不至于落得这样了。”韦崟豪爽仗义有侠气，听了这番话，立刻放开她。整理衣襟行礼道歉说：“不敢。”一会儿郑子回来了，和韦崟相视欢笑。从此以后，凡是任氏的柴米肉食等生活所需，都由韦崟供给。任氏时常来往，进出有时坐车骑马，有时步行，没有固定住处。韦崟天天和她游玩，非常欢快。每次互相亲昵，什么举动都有，却只是不发生关系而已。因此韦崟爱她敬她，一点也不吝啬，每餐每饭，不曾忘记她。任氏知道他爱自己，便趁机道谢说：“您这样厚爱我，实在惭愧。但我这丑陋的资质，不足以报答您的厚意；又不能辜负郑生，所以不能满足您的欢心。我是秦地人，从小在秦城长大。本家是艺人，中表姻亲多为别人的宠妾，因此长安城里的烟花柳巷，我全都熟悉。如果有美丽的女子，您喜欢却得不到的，我可以替您弄到手。愿意用这来报答您的恩德。”韦崟说：“太好了！”街市上有卖衣妇叫张十五娘，肌肤凝白，韦崟常常喜欢她。就问任氏认识她吗。任氏说：“那是我表姐的妹妹，弄来很容易。”十多天后，果然把她弄来了。几个月后韦崟厌烦了。任氏说：“市井之人容易弄到，不足以施展我的能力。如果有幽静绝世人家难弄到的，您说说看，我愿尽力去做。”韦崟说：“以前寒食节，我和几个人去千福寺游玩。看见刁缅将军在大殿上奏乐。有个善于吹笙的，十六岁年纪，双鬟垂到耳边，娇艳绝伦。你认识她吗？”任氏说：“那是宠奴。她的母亲就是我的表姐。可以求来。”韦崟在座下向她拜谢。任氏答应了他。于是她常出入刁家。一个多月后，韦崟催问她的计谋。任氏表示要双匹细绢作为贿赂。韦崟照办了。两天后，任氏正和韦崟吃饭，刁缅派仆人牵着黑马来接任氏。任氏听到召唤，笑着对韦崟说：“成了。”当初，任氏让宠奴生病，针药都不见效。她母亲和刁缅正非常忧愁，准备请巫师。任氏暗中贿赂了巫师，指她住的地方，让巫师说只要到那里去住就会吉利。等到来看病时，巫师说：“在家住不利，应该搬出去住到东南方某个地方，来吸取生气。”刁缅和她母亲察看那地方，正是任氏的宅子。刁缅于是请她同意让宠奴来住。任氏故意推辞说房子太狭隘，经再三请求才答应。于是用车载着衣服玩物，连她母亲一起送到任氏那儿。到了之后病就好了。没过几天，任氏秘密带韦崟去与她私通，一个月后她就怀孕了。她母亲害怕了，赶紧带她回去归附刁缅，从此断绝了往来。后来有一天，任氏对郑子说：“你能弄到五六千钱吗？我要用来谋利。”郑子说：“可以。”便向人借贷，得到六千钱。任氏说：“有个在市上卖马的人，那马的大腿上有块疤，可以
