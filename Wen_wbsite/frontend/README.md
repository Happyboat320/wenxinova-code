# 文心新述前端

React、Vite、TypeScript 网站前端。完整配置与部署说明见 [项目说明](../README.md) 和 [部署说明](../DEPLOYMENT.md)。

## 本地开发

### 环境准备

- 安装 [Node.js](https://nodejs.org/en)
- 安装 [pnpm](https://pnpm.io/installation)

### 操作步骤

- 安装依赖

```sh
pnpm install
```

- 启动 Dev Server

```sh
pnpm run dev
```

- 在浏览器访问 http://localhost:3000
